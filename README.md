Nuestro proyecto de curso se trata de un servidor del juego Minecraft, el cual tiene plugins, rangos, economia y tambien una tienda web.
Este es el readme general aqui se explicara como esta organizado todo del proyecto pero en cada apartado tiene un readme especifico de esa seccion por si se quiere saber mas de este tema en concreto.
En este repositorio tiene un esquema que es el siguiente: Carpetas principales: 
Configuracion maquinas: Aqui se podra encontrar todas las maquinas que hemos modificado a lo largo de este proyecto y cuales hemos usado, hay un apartado de cada maquina dentro de la carpeta y cada uno cuenta con la configuracion que se ha modificado de la maquina y con un readme de que se ha cambiado y el porque de ello.
Esquemas de red: Aqui son los esquemas que tenemos hecho de red ya sea tanto el logico como el fisico y la configuracion de los routers del fisico si se necesita mas informacion como he dicho antes hay un readme por cada apartado.
Pagina web: Es simplemente el codigo de la web que tenemos de la tienda con un readme para mas informacion.
Playbooks: En esta carpeta se podran encontrar todos los playbooks que se han creado a lo largo de la duracion de nuestro proyecto cada uno con su readme
